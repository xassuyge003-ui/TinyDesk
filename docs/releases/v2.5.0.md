# TinyDesk v2.5.0

V2.5 在 V2.0 桌面便签、重要日期和待办基础上，新增完全本地的长文档资料库。V1、V2 的 Release、安装包与源码快照继续保留，可独立下载。

## 主要更新

- 三栏资料库：目录、标签、收藏、最近打开、回收站和文档列表。
- SQLite FTS5 全文搜索：支持标题、正文、目录和标签检索。
- 原生富文本长文档：正文以 RTFD 保存，支持粗体、斜体、下划线、删除线、颜色、字号和字体预设。
- 十二套无横线国风花笺：主题统一覆盖左、中、右三栏和格式工具栏，包含山水、竹、兰、梅、莲、松、祥云与印章等传统元素。
- 导入 RTF、RTFD、TXT、Markdown；导出 RTF、RTFD、TXT、Markdown、PDF。
- 完整 ZIP 资料库备份与恢复，保留 RTFD 附件并兼容早期备份格式。
- 可将资料文档添加为桌面摘要卡片，双击返回资料库原文。

## 重要修复

- 修复长文档继续输入时正文被旧状态覆盖的问题。
- 修复桌面卡片点击后升到普通应用上方的问题。
- 修复花笺只改变右侧编辑器、没有同步覆盖整个资料库的问题。
- 修复深色及彩色花笺下标题、正文和状态文字对比度不足的问题，同时保留用户原始富文本颜色。

## 兼容与隐私

- V2.0 的 `workspace.json` 保持独立，不会迁入资料库数据库。
- 资料库只保存在本机 App Sandbox 内，不含账号、遥测、广告或联网内容。
- 最低系统为 macOS 14，安装包同时支持 Apple Silicon 与 Intel Mac。
- 安装包采用免费的 ad-hoc 签名，未经过 Developer ID 公证。首次启动请在 Finder 中按住 Control 点击 TinyDesk 并选择“打开”。
