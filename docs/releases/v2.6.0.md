# TinyDesk v2.6.0

V2.6 在 V2.5 桌面卡片与资料库基础上，集中修复数据安全、农历边界与界面可用性问题。V1、V2.0、V2.5 的 Release、安装包与源码快照继续保留，可独立下载。

## 数据与索引安全

- 修复全文搜索在收藏、回收站等元数据操作后丢失正文、FTS 索引孤儿行累积的问题；元数据写入改为保留 rowid 的 UPSERT，并在启动时自动修复历史索引。
- 修复农历冬月/腊月跨公历年时发生日错配、小月回退误用窗口末日的问题；严格闰月事件可在完整农历周期内找到下一次闰月。
- 修复高版本工作区被当作损坏文件备份并重建的问题；现在进入只读展示模式并保留原文件。
- 修复 ZIP 备份读取忽略 extra field、不校验 CRC 的问题；备份缺正文/缺文件时明确报错；恢复失败只回滚本次新建的目录、标签与文档。
- 修复所有退出路径（菜单、AppleScript、系统终止）未最终落盘、SwiftUI 重建导致桌面卡片面板重复的问题。
- 修复 PDF 导出生成单页超长文件的问题；现在按纸张尺寸真正分页。

## 资料库体验

- 搜索增加“搜索中 / 无结果 / 失败”状态，不再把无结果误显示为全部文档。
- 新增筛选胶囊（目录、标签、搜索词）、各场景专用空状态与删除二次确认。
- 资料库错误横幅、导入文档即时生成字数和摘要、导出/备份前自动同步未保存正文。
- “最近打开”改为按真实访问时间排序。

## 桌面卡片与重要日期

- 修复仿宋等字体无粗体字重时加粗静默失效的问题。
- 修复首次启动过早请求通知权限的问题；只有启用提醒后才请求。
- 修复系统日历重复规则忽略 interval/end、非全天事件静默变全天的问题。
- 资料摘要卡与资料库文档实时同步，单击即可打开资料库原文（窗口未打开时自动打开）。
- 新建便签/待办不再写入教学示例数据；重要日期紧凑日历点击日期可查看并编辑事件。

## 兼容与隐私

- V2.5 的 `workspace.json` 与资料库数据格式兼容，数据库升级自动补充新字段。
- 资料库只保存在本机 App Sandbox 内，不含账号、遥测、广告或联网内容。
- 最低系统为 macOS 14，安装包同时支持 Apple Silicon 与 Intel Mac。
- 安装包采用免费的 ad-hoc 签名，未经过 Developer ID 公证。首次启动请在 Finder 中按住 Control 点击 TinyDesk 并选择“打开”。
