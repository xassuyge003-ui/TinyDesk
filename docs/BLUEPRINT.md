# TinyDesk 产品蓝图

## 定位

TinyDesk 为希望在 macOS 桌面快速记录和查看个人事项的用户提供一组可直接编辑的原生卡片。
产品只聚焦便签、重要日期与待办，不包含汇率、资讯或其他联网聚合。

## 产品原则

1. **直接操作**：用户无需跳转配置页即可编辑桌面内容。
2. **克制稳定**：每张卡片只承担一种任务，尺寸变化不破坏信息层级。
3. **本地优先**：内容默认不离开 Mac，不引入账号、追踪或网络权限。
4. **免费可构建**：不依赖 App Group、云服务或付费开发者能力。
5. **可维护**：纯数据核心与 macOS UI 分离，工作区格式有版本号和自检。

## v1.0.0 范围

| 模块 | 能力 |
|---|---|
| 便签 | 多卡片、标题与正文直接编辑 |
| 重要日期 | 日历/列表、分类筛选、一次性/每年、生日年龄、纪念周年、本地通知 |
| 待办 | 新增、编辑、完成划线、完成项下移、状态筛选、跨日逾期提示、优先级、计划日期 |
| 外观 | 每张卡片独立切换颜色及毛玻璃、透明、不透明背景 |
| 桌面窗口 | 固定桌面层、移动、缩放、跨 Space、位置锁定与恢复、显示/隐藏 |
| 控制中心 | 新建、定位、尺寸、颜色、背景风格、位置锁定、批量显示/隐藏、删除 |
| 菜单栏 | 控制中心入口、快速新建、卡片定位、退出 |
| 数据 | App Sandbox 内的版本化 JSON、原子写入、损坏备份 |

## v1.1.0 增量

- 便签支持选中文字后设置颜色、粗体、斜体、下划线和删除线。
- 富文本数据与纯文本摘要一同保存在本地工作区，旧版纯文本便签无需迁移即可继续编辑。

## 非目标

- 不进入 macOS 系统小组件图库。
- 不提供汇率、新闻、RSS 等联网内容。
- 不依赖 App Group、iCloud 或付费 Apple Developer Program。
- 不承诺窗口显示在全屏独占应用之上；卡片的默认职责是融入桌面。

## 后续方向

- 工作区导入/导出与显式备份。
- 透明度强度调节。
- 待办拖拽排序与多清单。
- 农历生日、闰月规则与系统日历导入；当前 schema 已预留日历类型字段。
- 自动化测试覆盖存储迁移和窗口 frame 恢复。
